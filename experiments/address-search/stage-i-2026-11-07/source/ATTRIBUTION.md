# GeoNames source snapshot

This folder preserves the official daily `cities15000.zip` archive from GeoNames, retrieved on 2026-11-07 for a bounded address-search fallback review. Source URL, HTTP retrieval metadata, artifact SHA-256 and CC BY 4.0 attribution are in `source-manifest.json`.

Only four city records are admitted into the limited fallback snapshot. The full archive is retained solely as a reproducible source artifact; it is not a new runtime gazetteer. The runtime pilot remains independently feature-gated. GeoNames is not used for street or house-level claims.
