# Решения владельца — тарифные исследования «Из А в Б»

## 27.10.2026 — последняя имеющаяся редакция цены обязательна

Прямая инструкция владельца: принимать тариф из последнего имеющегося документа за рабочую истину до более нового документа, вне зависимости от его возраста. См. [полный нормативный текст](../../docs/TARIFF_SOURCE_POLICY.md).

**Приоритет:** новая редакция документа по конкретной тарифной системе/профилю с даты действия > предыдущая. Истечение времени без обнаружения замены больше не является основанием для `unknown`. Сохраняются строгие проверки геометрии, выбора оплачиваемых продуктов, направления, категории, способа оплаты и повторных списаний. Обновление денежной политики **не авторизует** подключение эксперимента в приложение или выдуманную плату.

**Пересмотр прежних выводов:** для B05 приказывать №58 с ценами использовать как последнюю доступную тарифную основу. Старое «не подтверждена актуальность цен в октябре» убрать из активной причины блокировки; остаётся «не доказано, какие участки оплачиваются через конкретную кассовую ветвь». По М11 приказ №274 и по М12 приказ №302 аналогично использовать внутри их собственных систем. История экспериментов не стирается.

**Решение не равно:** подтверждение полного маршрута; разрешение суммировать 517–544+544–589; отправка оператору; выпуск в Production.
