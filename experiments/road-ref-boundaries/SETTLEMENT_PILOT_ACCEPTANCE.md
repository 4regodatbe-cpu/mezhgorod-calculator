# Приёмка ограниченного каталога населённых пунктов

Статус 24.10.2026: критерии подготовлены; проверки данных NOT_STARTED.
Источник/лицензия уже рассмотрены в [source intake](../../docs/checkpoints/2026-10-24-address-coordinate-source-intake-DONE.md). Поставка заблокирована DNS; повторять её без изменения доступа не нужно. Это спецификация отчёта пилота, не импорт и не runtime-модуль.

| Проверка | Требуемое evidence | Условие остановки |
| --- | --- | --- |
| Поставка | URL, UTC-время, HTTP/redirects, размер, validators; SHA256 реально полученного архива | Неизвестный размер либо сумма RU/UA >50MiB: не начинать B |
| Целостность | ZIP integrity; список членов, лимит распакованных байтов, число строк/отклонений | Повреждение, неожиданные пути/формат или превышение заранее заданного B-STARTED лимита |
| Provenance | Для каждого id: country dump, строка/версия, source date; importer version; исходные поля сохранены | Нет цепочки от записи до сохранённого источника |
| Координаты | featureClass P; конечные числа WGS84; исходный порядок lat/lon; id, admin codes и featureCode | Невалидная запись исключается с причиной; наличие валидного диапазона само по себе не доказывает точность |
| Приоритетная география | Отдельно ДНР, ЛНР, Запорожская, Херсонская, Крым: фактические count по проверенным versioned polygons, outside/boundary/unknown отдельно | Нет polygon/version либо нет данных: статус UNKNOWN; countryCode не заменяет географическую проверку |
| Контрольные имена | Москва, Краснодар, Донецк, Луганск, Ялта, Севастополь, Тарасовка, Черноморское: ВСЕ кандидаты, id/admin/координаты/причина соответствия | Не выбирать первую строку автоматически; отсутствующий кандидат остаётся MISSING |
| Русские алиасы | Основное имя отдельно от aliases; ru только с языковой меткой V2; preferred/historical/date flags | Country alternatenames без языка нельзя объявить проверенными ru aliases; V2 пока не скачивать |
| Омонимы | Список id, одинаковые normalized names, раздельные admin labels и явно выбираемые варианты | Два разных id нельзя склеить только по имени; неразличимый label требует исправления |
| Точность | Для каждого будущего runtime-допуска независимое подтверждение населённого пункта/положения с источником/датой и явным review | Отсутствие независимого подтверждения не компенсируется успешным парсингом или совпадением имени |
| Размер и поиск | Размер исходных/производных данных, число records/aliases, память и локальный bounded lookup измерены | Лимиты implementation STARTED не определены или превышены — не внедрять |
| Лицензия | Attribution GeoNames/CC BY4.0 + URL + изменения/дата, место показа пользователю | Внутренний manifest без пользовательской атрибуции недостаточен |

Выход C: таблица фактических записей и verdict по каждой строке (PASS / MISSING / AMBIGUOUS / UNKNOWN / REJECTED), manifest и отдельный summary ограничений. Восемь имён — диагностическая выборка, не доказательство полноты регионов. Counts не дают полноту без независимого эталона. Не переносить координаты из offline benchmark.

Пилот может завершиться частичным пригодным набором, но не разрешает активацию всего каталога. Перед реализацией — отдельный STARTED; модуль по умолчанию выключен, тесты по [контракту интеграции](SETTLEMENT_FALLBACK_INTEGRATION.md). Адреса улиц/домов не обещаются. Маршруты, цены и обязательные toll guards вне этого этапа.
