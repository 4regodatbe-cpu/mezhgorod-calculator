# Журнал песочницы: toll OD matrix

## 2026-10-08 — блок 1. Изоляция и первый автономный движок

**Рабочая ветка:** `experiment/toll-od-matrix-2026-10-08` из `64631d23dc7ca44febafb9ebf1136162c7af9e82` (PR #12). До написания журнала сделаны отдельные коммиты:
- `0be27089d376cde02a3149968cf89a1ab404f02d` — сохранены 11 побайтно идентичных исходных файлов М-4 и М-11.
- `9d4ce113b2d08ae6beafc6dec14f3331dea579e5` — создан автономный fail-closed движок, M11 partial matrix и тестовый файл.

**Что изменено и зачем:** внутри `experiments/toll-od-matrix/` сохранены исходники, затем создан независимый directed entry/exit lookup для устранения повторных поэлементных начислений в непрерывном проезде. Источники тарифов и маршрутные доказательства не смешаны.

**Подтверждено:** в исходном M11 A1 snapshot 22 точки и две непосредственно проверенные текущие пары p58→p593 и p58→p679; остальные пары не проверены. В песочницу перенесены только эти две пары. 16/16 deterministic JS assertions на функцияx движка успешно выполнены перед фиксацией. Это не запуск Node test runner.

**Не проверено:** `node --test`, `tsc`, lint, Next build, CI, live route geometry, текущие официальные OD-цены М-4, holidays schedule. Не делать из них выводов.

**Решения:** рабочий `/v2`, API, основные рабочие ветки, PR и Production не менять. Никаких расчётных тарифов из разности или суммы прежних ПВП. Обратная направленность — отдельная ячейка; неизвестная цена всегда `null`. В `source/` или `sources/` данные не являются рабочими импортами приложения.

**Дальше:** добавить подтверждённый справочник физических въездов/съездов М-4 и частичную официальную OD-матрицу; следом отдельный crossing detector по route geometry. Только после этого выполнять независимую валидацию на маршрутах и обсуждать интеграцию.

## 2026-10-08 — блок 3. Строгая геометрия, композиция тарифов и внешняя инвентаризация съездов

- **Новые файлы:** `od-geometry.mjs` / `od-geometry.test.mjs`: извлекают **непрерывные** платные проезды на базе полного независимого map-matched графа (каждое дорожное ребро с проверенным OSM way/node); каждый переход въезд/выезд требует совпадения ID топологического узла и координат в пределах 35 м, а также явной верифицированной точки и направления. Близость к ПВП не считается доказательством. При дыре геометрии или неполном evidence — unknown, не частичная цена.
- `od-sandbox-quote.mjs` / `.test.mjs` соединяют экстрактор с уже созданной прямой M11 матрицей. Получение нескольких отдельных подтверждённых проходов, несколько систем, отсутствие части тарифа и проверенная бесплатность обрабатываются без переноса в V2. При некорректном тарифном файле теперь возвращается unknown/null без исключения.
- **Матрица М-4:** `matrix/m4.json` — явная пустая направленная матрица, `pairs=[]`: 0 подтверждённых OD цен; не подставлены фиктивные тарифы за километры или суммы соседних ПВП. Исходные 20 пунктов оплаты в `inventory/m4-payment-facilities.json` остаются отдельным фактом.
- **Кандидаты съездов:** `inventory/m4-candidate-interchanges.json` — 23 упоминания городских въездов/съездов в Т—Ж (03.06.2026) и 30 километровых ориентиров MultiGO (08.10.2026), всего 53 записи **только для поиска**, не подтверждённые OSM узлы. Ссылки, классификация и ограничения: `inventory/M4_INTERCHANGES.md`.
- **Важная проверка правил:** официальные правила Автодора описывают на большей части М-4 открытый сбор через ПВП и частично бесплатный проезд между свободными съездами; смешанные зоны 401–464 и 633–741 имеют отдельные условия. Источник: https://avtodor-tr.ru/company/docs/proezd/ и https://avtodor-tr.ru/info/legal-info/pravila-proezda/. Это подтверждает, что простое предположение «пересёк М-4 значит платный» некорректно.
- **Проверки локально:** на локальных копиях экспериментальных модулей и эквивалентных фиксированных M11 fixture (2 подтверждённые пары) запущено `node --test ...` — **51/51 тестов успешно** (16 OD lookup, 22 extractor, 13 combined); исходный JS-код тестов и экстрактора сохранён в GitHub. Это только синтетический offline test, не реальная трасса. Полная сборка Next, external routing, официальная новая матрица и GitHub CI не запускались.
- **Ограничение:** попытка добавить отдельный GitHub Actions workflow для песочницы была отклонена проверкой безопасности инструмента. Файл workflow не создан, CI не запускался; не пытаться обходить это ограничение.
- **Главный незакрытый вопрос:** OSM node/way IDs и настоящая направленная доступность физических съездов ещё не получены, реальная маршрутная геометрия не прошла тест. Source article KM ≠ precise coordinate. Нельзя считать ни один из 53 кандидатов разрешённым въездом для live pricing.
- **Следующий шаг:** получить разрешённым способом OSM топологический граф реальных съездов М-4 (оба направления), связать их с подтверждёнными PVP событиями и официальными тарифами, заполнить directed OD только по независимо подтверждённым парам. Затем проверить реальные поездки и границы тарифных периодов, после чего обсуждать интеграцию. Без явного указания пользователя не изменять Production.
