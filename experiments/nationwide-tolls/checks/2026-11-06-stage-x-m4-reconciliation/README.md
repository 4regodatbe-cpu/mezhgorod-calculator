## Вывод по источнику

В сохранённом скане приказа «Автодора» №58 от 27.02.2026 (действует с 02.03.2026; локальный PDF SHA256 `25fdb9a430934f47617c8cc1563f95e49c6ebe41c6303e9bd67465b3c568662d`) для категории I есть две временные колонки — пн–чт и пт–вс. Категории I–IV представлены отдельными строками, а не четырьмя наборами payment/transponder-колонок категории I.

Визуальная проверка исходного PDF подтверждает все контрольные строки (значения I категории пн–чт / пт–вс):

| 71 | 310 / 400 |
| 133 | 400 / 500 |
| 803 | 560 / 620 |
| 1184 | 300 / 350 |

Для проверки структуры исходника также сверены соседние строки категорий: на ПВП 62 категории II/III/IV — 240/240, 260/260, 480/480 ₽; на ПВП 71 — 450/450, 500/500, 820/820 ₽. Раскладка Stage W ошибочно прочитала соседние значения строк категорий как альтернативные тарифы категории I.

Исторический файл `source-snapshots/m4-posted-category1-tariffs-2026-09-29.json` содержит четыре поля для категории I, но исходная HTML-разметка/полученные байты, HTTP-заголовки и фактический timestamp получения не сохранены. Stage W журналировал обращение к официальной странице 2026-11-06; дата `2026-09-29` в записи была перенесена в качестве observation date из `m4-data.ts`, а не подтверждена метаданными raw response. Поэтому установить, какой именно HTML-вариант был получен и как он был физически сверстан, невозможно. Доступный snapshot JSON и генератор показывают только уже нормализованную, но неверно сопоставленную четырёхколоночную модель. Свежая независимая загрузка HTML в этой среде не состоялась: сетевой proxy на `:8080` отказал в соединении. В локальных материалах не найден более поздний официальный приказ; это не доказывает, что такого документа нет на сайте.

Расхождение Stage W `38/42` относится к сравнению неверно сформированной no-transponder выборки с Category I приказа №58. Это не доказательство новой ставки или редакции. Изменение тарифа на основании этих 38 ячеек отвергнуто. Текущий Stage X возвращается к сохранённым ставкам №58; более поздняя действующая редакция должна быть подтверждена отдельным датированным официальным документом до дальнейшего применения.
