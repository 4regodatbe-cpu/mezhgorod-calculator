# Первичная физическая привязка p258

Три bounded GET: exact node3183012434, way795246101/full и локальная карта вокруг наблюдаемого съезда. Полные байты, HTTP-метаданные, SHA и progress сохранены. Новых routing/trace нет. Направление и operator identity описаны в binding-proof.json; runtime использует только directed-exit.json.

OSM: © OpenStreetMap contributors, ODbL, https://www.openstreetmap.org/copyright . Карта/объекты являются пространственными данными; денежные строки берутся из ранее проверенного первичного приказа оператора №274, не из OSM. Связь источников — source-derived physical binding, без независимого операторского OD-чека.

Имя здания «ПВП „Торжок“ —258км» относится к комплексу; gate не объявлен находящимся внутри полигона здания. Обратное направление5286254520 сохраняется вraw, но его цена этим изменением не включается. Не расширять scope по одному ближайшему объекту.
