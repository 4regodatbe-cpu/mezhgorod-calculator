## Целевая архитектура

1. Route Builder — несколько независимых кандидатов маршрута.
2. Map Matcher / Toll Validator — независимая проверка фактических дорожных рёбер и ПВП.
3. Toll Engine — расчёт платы по реальным ПВП/рамкам/системам entry-exit/free-flow.
4. Free Route Arbiter — бесплатный маршрут считается бесплатным только после независимой проверки.
5. Fallback — проверенная база и коридорная логика используются только как резерв.
6. Regression QA — автоматическая проверка эталонных проблемных направлений после изменений.

## Принцип безопасности изменений

- Не расширять радиусы, чтобы скрыть отсутствие данных.
- Радиус кандидата не является доказательством пересечения.
- Не подставлять цену другой пары городов.
- Не считать `avoid tolls` доказательством бесплатности.
- Не выдавать точную сумму из неполного набора ПВП.
- Не складывать entry/exit ПВП mixed-систем как независимые тарифы.
- Неподтверждённые кандидаты не становятся полной уверенностью автоматически.
- Любая новая схема сначала диагностическая и проходит regression, только потом становится основной.
