# Межгород Calc — VK Mini App

Отдельная версия калькулятора для размещения на хостинге VK. Существующий сайт и Android-приложение не изменяются.

## Публикация

1. `npm install`
2. `npm run deploy`
3. Авторизоваться во VK в открывшемся окне и подтвердить публикацию приложения № 54784735.
4. В настройках приложения включить состояние «Включено» и сохранить.

После первой публикации ограничьте ключ JavaScript API Яндекс Карт по HTTP Referer адресами хостинга VK.
