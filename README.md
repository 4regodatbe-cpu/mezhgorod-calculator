# Межгород Calc 2.0

Калькулятор междугородних поездок с обычным и двойным тарифом, сравнением быстрого и подтверждённого бесплатного маршрута и отдельным расчётом платных дорог.

Основной интерфейс: `/v2`. Корневой адрес перенаправляет на актуальную версию калькулятора.

Маршрутизация проверяется по нескольким независимым источникам. Стоимость платных дорог рассчитывается отдельными локальными движками и контрольными данными; неполные или неподтверждённые значения не выдаются как точная сумма.

## Проверка перед публикацией

```bash
pnpm install --frozen-lockfile
pnpm lint
pnpm build
node scripts/segment10-production-readiness.mjs
```

Полный набор regression- и live-проверок выполняет GitHub Actions workflow `Calculator final gate`.

## Android

Актуальная оболочка находится в `android-app-v2` и открывает `/v2`. Workflow `Android APK 2.0` собирает `Mezhgorod-Calc-2.apk`.
