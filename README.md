# «Из А в Б» — V1 Release

Калькулятор междугородних поездок с обычным и двойным тарифом, сравнением быстрого и подтверждённого бесплатного маршрута и отдельным расчётом платных дорог.

Публичный V1 Release использует технический URL `/v3`; корневой адрес перенаправляет на него. Прежний `/v2` сохранён и продолжает собираться. Продуктовое имя не меняет API, тарифы или правила маршрутизации.

Одна активная песочница разработки — ветка `fix/v3-missing-route-prices-2026-10-15` и [её инструкция](sandbox/README.md). [Каталог исторических версий](archive/versions/README.md) и [ограниченный архив исследований](archive/research/README.md) содержат восстановимые файлы с SHA256. Предрелизный V3-архив пока доступен только локально: GitHub Release upload завершился HTTP 401. Исходные исследовательские файлы не удалены; [точный статус реорганизации](docs/reorganization/FINAL_STATUS.md).

Маршрутизация проверяется по нескольким независимым источникам. Стоимость платных дорог рассчитывается отдельными локальными движками и контрольными данными; неполные или неподтверждённые значения не выдаются как точная сумма.

## Для следующего разработчика

Начните с [WORK_STATE](docs/WORK_STATE.md): здесь актуальная точка продолжения — рабочая ветка, PR, сделанное, риски и следующий шаг. Правила handoff и журнала находятся в [AGENTS.md](AGENTS.md). Затем читайте только связанные спецификации/checkpoints.

## Проверка перед публикацией

```bash
pnpm install --frozen-lockfile
pnpm lint
pnpm build
node scripts/segment10-production-readiness.mjs
```

Полный набор regression- и live-проверок выполняет GitHub Actions workflow `Calculator final gate`.

## Android

Актуальная оболочка находится в `android-app-v2` и открывает `/v2`. Workflow `Android APK 2.0` собирает `Mezhgorod-Calc-2.apk`.
