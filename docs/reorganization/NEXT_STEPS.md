# Реорганизация — следующие шаги

1. A DONE: `INVENTORY.json` и проверка счётчиков сохранены.
2. BLOCKED: получить однозначное разрешение auto-review на следующий обычный fast-forward push инвентаря A; затем remote readback. Текущий remote `320c50d4...`, локальный A `4059eb68...`; при изменении remote сначала сверить ancestry.
3. B: оценить и создать три физических архива из точных SHA; проверить извлечение и Git-сопоставление, выбрать допустимое GitHub-хранилище по размеру.
4. C: архивировать только подтверждённо неиспользуемые исследования, проверить восстановление.
5. D/E/F: только после сохранения архивов — консервативная очистка, полные обязательные проверки, документация и remote readback.

Критерий DONE каждого пункта — фактические артефакты/проверки, а не наличие README или Git-ссылки.
