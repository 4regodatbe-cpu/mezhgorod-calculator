# Реорганизация — следующие шаги

1. A: построить и проверить `INVENTORY.json` от актуального tracked-дерева.
2. B: оценить и создать три физических архива из точных SHA; проверить извлечение и Git-сопоставление, выбрать допустимое GitHub-хранилище по размеру.
3. C: архивировать только подтверждённо неиспользуемые исследования, проверить восстановление.
4. D/E/F: только после сохранения архивов — консервативная очистка, полные обязательные проверки, документация и remote readback.

Критерий DONE каждого пункта — фактические артефакты/проверки, а не наличие README или Git-ссылки.
