## Объём, фактический источник и результат

Выполнено ровно четыре ограниченных поисковых запроса и изучены три первичных документа, без ZIP, live Photon/API, route replay и локальных code tests:

1. GeoNames, собственная страница данных и лицензии: https://www.geonames.org/export/ — country dumps, ежедневная публикация, CC BY, коммерческое применение с атрибуцией, «as is».
2. GeoNames, официальная спецификация: https://download.geonames.org/export/dump/readme.txt — `XX.zip`, `allCountries.zip`, поля geonameid/name/asciiname/alternatenames/latitude/longitude/feature class/code/country/admin1…4/population/modification date; `alternateNamesV2.zip` с языком, historical/preferred флагами и временными интервалами. `feature class P` относится к населённым пунктам; координаты WGS84 в исходных данных GeoNames. `cities500.zip` урезает малые населённые пункты, поэтому не годится единственным полным покрытием.
3. Geofabrik / OpenStreetMap, первичный extract РФ: https://download.geofabrik.de/russia.html — ~3.9 GB `russia-latest.osm.pbf`, ODbL 1.0, есть региональные выгрузки и дублированное включение Крыма; требует отдельной схемы лицензии/ETL, для узкого пилота менее удобен.

**Решение:** GeoNames — **CANDIDATE_FOR_LIMITED_OFFLINE_PILOT**, НЕ approved for runtime. Основная рекомендация: отдельный локальный геосправочник городов/посёлков из ограниченно проверенных `RU.zip` + `UA.zip` и необходимых соседних country dumps, затем языковые варианты `alternateNamesV2` только по сохранённым geonameid. Не объявлять единым покрытием все приоритетные области на основании countryCode; сначала проверять географическое включение по проверенным полигонам и координатам. Никаких координат из имени, RuWiki-only index или benchmark.

| Критерий | Вывод / непроверенное |
| --- | --- |
| Лицензия | GeoNames CC BY 4.0, коммерчески допустима с текстовой атрибуцией, ссылкой на источник/лицензию и указанием преобразований. Исходная дата и версия обязательны в manifest. |
| География | Есть страновые RU/UA dumps и мировой dump. **Не доказаны** реальные coverage/counts Донецка, Луганска, ДНР/ЛНР, Запорожской, Херсонской, Крыма и малых населённых пунктов. Политические границы/ISO-код не заменяют продуктовые полигоны. |
| Названия | Основное имя и aliases, отдельно `ru` в V2. У конкретной записи русский alias может отсутствовать; исторические названия помечать, не смешивать без маркировки. |
| Дубликаты | Несколько результатов одного имени хранить раздельно по geonameid, координате, featureCode и country/admin1/admin2; пользователь выбирает явную строку, не автоматически первое совпадение. |
| Координаты/происхождение | Decimal WGS84, GeoNames объединяет внешние и wiki-источники. Это точки населённых пунктов, не адрес дома, не въезд/road snap и не гарантия точности. Не использовать автоматически для расчёта до проверки. |
| Размер | Country dumps/ZIP и allCountries предусмотрены; фактические размеры RU/UA, итоговый размер после фильтров/индекса, checksum, квоты приложения и холодный поиск **не измерены**: перед импортом проверить отдельно. OSM РФ ~3.9 GB, отклонён для данного пилота. |
| Независимость | Локальная выгрузка GeoNames независима от `photon.komoot.io` при его полном 503. Бесплатный GeoNames web API имеет лимиты и не выбран как production fallback. |
| Модульность | Реализуемо через новый `settlementFallback` с отдельными files/data/tests/feature switch, no-network lookup и structured `unavailable/ambiguous`. Пока лишь проект интеграции. |
