# Уточнение: недостающие тарифы не блокируют распознавание границ

Дата:23.10.2026 МСК. Статус: DONE — фиксация решения; DEFERRED — реализация.

Пользователь уточнил, что недостающие цены допустимо оставить неизвестными и заполнить позднее. Исправлена ошибочная зависимость предыдущего плана «сначала дождаться тарифов, затем дорабатывать». Распознавание конкретной направленной развязки и выбор существующего тарифного вектора могут разрабатываться и проверяться независимо от наличия числовой цены. Стоимость unknown не мешает подтвердить правильный въезд/съезд. При этом полная сумма остаётся неизвестной, пока отсутствует хотя бы одна нужная цена.

Различать результаты: граница не определена; граница/вектор определены, цена неизвестна; вектор и цена известны. Это требования будущей реализации, не новые реализованные статусы API/UI. OSM также разделяет признак платности toll и сумму charge: https://wiki.openstreetmap.org/wiki/Key:toll (просмотрено23.10.2026). Цена из OSM не импортировалась.

Предыдущее прямое указание «не приступай к этой доработке» не отменено явной командой начать. Реализация пока отложена; ожидание тарифов из условий разработки убрано. При новом поручении сначала проверить сохранённый проблемный М4-маршрут новых территорий на правильную границу/вектор, затем отдельно на наличие цены.
