## Изменение

- V3 отличает полностью внутренний маршрут только после проверки обоих endpoints и каждого куска подтверждённой геометрии. Внешний детур отклоняется до выбора самого быстрого кандидата; для смешанного маршрута прежний split сохранён.
- При двух особых endpoints `modeOverride: standard` больше не может обнулить специальный пробег. API добавляет необязательный `specialOnly`; `mode: dual` сохраняет совместимость контракта. Валидатор проверяет, что четыре суммы состоят из единственного специального сегмента.
- Форма V3 после подтверждённого результата показывает одну группу из четырёх особых ставок, карточка и копия называют применённый тариф. Shared-компоненты по умолчанию не меняют /v2.
- Утверждённые базовые ставки 70/80/90/110 ₽/км, срочная надбавка, округление, тарифы дорог и выбор самого быстрого маршрута не менялись.
