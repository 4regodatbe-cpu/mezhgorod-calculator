## Назначение

Standalone-калькулятор межгорода; основной интерфейс — V2 (/v2). Текущая работа PR #10 — политика особых тарифных территорий в существующем V2 маршруте и отдельном toll engine.

Основные утверждённые правила: полные ADM1-полигоны Донецкой, Луганской, Запорожской и Херсонской областей; координатная классификация endpoints; Крым тарифицируется обычно; тариф разделяется по фактической геометрии; обычным endpoints запрещён транзит через особую зону; unknown toll не становится бесплатным; Крымская альтернатива допустима только после подтверждённой per-leg проверки времени ≤50%; ручной режим сохраняется в сессии и возвращается к automatic после 30 минут бездействия. Полный источник — [SPECIAL_TERRITORY_POLICY.md](SPECIAL_TERRITORY_POLICY.md).
