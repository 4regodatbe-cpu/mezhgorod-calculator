# Special territory boundary data

- **Source:** UN OCHA / HDX, Ukraine Common Operational Dataset – Administrative Boundaries (COD-AB), ADM1, version v05.
- **Dataset page:** https://data.humdata.org/dataset/cod-ab-ukr
- **OCHA hosted boundary service:** https://gis.unocha.org/server/rest/services/Hosted/cod_ab_ukr_v05/FeatureServer
- **License:** Creative Commons Attribution 4.0 International (CC BY 4.0).
- **Boundary validity date in source:** 2025-09-01.
- **Coordinate reference:** CRS84, coordinate order longitude then latitude (equivalent to WGS84 for this GeoJSON).
- **Selected admin codes:** UA14 Donetska, UA44 Luhanska, UA23 Zaporizka, UA65 Khersonska.
- **Selection:** Four complete oblast geometries copied from the user-provided `ukr_admin1.geojson`; all other features were excluded. Geometry coordinates and source attributes are preserved, with `special_territory_id` added for the calculator mapping.
- **Scope:** This is a broad administrative geofence for the tariff rule. It does not encode the active line of contact, road access, or a safety assessment.

Attribution: UN OCHA / HDX, Ukraine COD-AB v05, CC BY 4.0. The boundary file is used as a source dataset and does not establish legal status or current travel conditions.
